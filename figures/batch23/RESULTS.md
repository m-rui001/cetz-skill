## fig70-triad（单位基 i/j/k 与任意基 e1/e2/e3 对照）

两栏共用"细轴 + 粗矢量 + 弯曲引线"三层结构。要点：
- 轴用 1.1pt 细线、粗矢量用 1.9pt（第一版 2.6pt，比原书粗一倍，是唯一一次重试）。
- 刻度短线用 `tick(p, d, s)`：过刻度点沿**垂直于该轴**的方向画 ±s 小段，
  x 轴的垂直方向要预先算好 `px = (-uy, ux)`，不能沿用 y/z 的轴向。
- 引线（label→矢量）用 `bezier(起点, 终点, c1, c2)` + `mark:(end:">")`，
  终点切向由 **c2→终点** 决定：想让箭头"往下扎"就把 c2 放在终点上方，
  否则箭头会朝反方向（panel b 的 e1 引线第一版就朝反了）。

## fig71-dv（三栏速度变化 A/B/C）

A/B 两栏是同一套局部坐标分别旋转 0°/−45°：`panel(ox, oy, ang, tag)` 内部
`R(p)` 旋转后再平移，**文字锚点跟着旋转、文字本身保持水平**（只旋转坐标不旋转内容），
和原书一致。

C 栏原书**不是**纯旋转：圆标在两组箭头的中间偏下，而 v_initial/−v_initial 在圆标左上方。
硬套旋转会把圆标挤到箭头线上。做法是给 C 单独写显式坐标（三行 line + 一个 circle），
保留 A/B 走闭包。结论：`panel(旋转)` 闭包适合"确实只是转角不同"的栏，
一旦原书某一栏的相对位置被作者重排，就该为它破例而不是加参数。

## fig72-vectortri（切向/向心/合加速度）

- 虚线圆弧用三点定圆反解：读原图弧上三个点（下端、P、右上端）解
  `x²+y²+Dx+Ey=0` 得圆心 `(3.06,-2.72)`、`r=4.1`，再反算三点的极角
  （203.4° / 137.9° / 61°）。`arc` 只会 CCW 扫，画 CW 弧就把起止角对调
  （`start: 61deg, stop: 203deg`），扫到的是同一段。
- 合矢量端点直接取 `S = T + C`，两条虚边 `T–S`、`C–S` 自动闭合成平行四边形，
  不要各自估像素（否则两虚边交不到一点）。
- 原书的虚线是**长划**，`dash: "dashed"` 太密，改
  `(dash: (array: (9pt, 6pt)), thickness: 1.3pt)` 才像。
