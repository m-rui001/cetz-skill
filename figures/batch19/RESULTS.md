## fig59 失败—修正记录（圆角矩形）

CeTZ 0.4.2 的 `rect` 只接受两个角点，没有 `radius:`，也没有 `rounded-rect`。
手写圆角方块时踩了两个独立的错：

1. 第一条错误版本用 `arc2` 包一层"stop<start 就 +360deg"的补丁，弧画在方块
   外侧变成断开的"C"形。
2. 修正弧角度后仍然不对：四条**边**的端点沿错了轴——顶边/底边应沿法向 n
   偏移 `+rr*n` / `-rr*n`，左右两边应沿 u 偏移 `+rr*u` / `-rr*u`；
   写成沿 u 偏移顶边、沿 n 偏移侧边后，弧的切点与边的端点不重合，
   圆角弧整体缩进方块内部，画出"四瓣内凹花"。

正确的四元组（角心 `ca(i,j)`，弧窗从 `a+90*(j==1?0:...)` 推）：

```
// 边：顶/底沿 n 偏移，左/右沿 u 偏移，两端都同向
line(ca(-1,1)+rr*n, ca(1,1)+rr*n)      // 顶
line(ca(-1,-1)-rr*n, ca(1,-1)-rr*n)    // 底
line(ca(1,-1)+rr*u, ca(1,1)+rr*u)      // 右
line(ca(-1,-1)-rr*u, ca(-1,1)-rr*u)    // 左
// 角弧：四个象窗正好是 [a,a+90] [a+90,a+180] [a+180,a+270] [a+270,a+360]
// 对应角 (1,1) (-1,1) (-1,-1) (1,-1)，起点 = 角心 + rr*(cos st, sin st)
```

`arc` 的 position 语义经单独 probe 确认：`position = 圆心 + r*(cos start, sin start)`，
`start→stop` 逆时针；probe 文件比反复改主图快得多。

## fig60 失败—修正记录（斜投影退化）

首版用 `S(x,y,z) = (y - k*x, z - k*x)`（两个轴同系数）。此时平面 `y = z`
整体投影到直线 `X = Y` 上，立方体底部那条隐藏边正好压在 x 轴上，
x 轴看起来变成点线。把两个系数分开（`k=.55, m=.42`）后简并消失，
深度方向仍约 37°，观感与原图一致。

另外：`h` 从 1.5 放大到 2.0 并把 `(0,0,0)`、`Right`、`Front` 三个标签重新
按锚点错开，才消掉第一版的文字重叠。
