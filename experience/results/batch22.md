## fig68-disk（刚体角动量盘，z′–y′ 平面内三个质点）

要素逐项核对：z′ 竖轴 + y′ 横轴（各一个箭头）、轴上的旋转椭圆环＋环右端实心小箭头、
m5/m4/m1 三个实心点、三条 r 矢量（原点→质点，箭头落在点上）、三条 L 矢量（质点→切向，
与 r 严格垂直）、⊗×2 与 ⊙×1、三行 L=m r×v 公式、三处 "Velocity … is into/out of page"。

关键做法：
- L 方向不用量像素，直接取 r 的法向。m5=(2.23,3.77) 时法向 (-3.77,2.23)/4.39，
  乘长度 1.58 得 tip=(0.85,4.54)，与原图像素位置误差 <0.05 单位；m4、m1 同理，
  只是符号相反（v4 出纸面 ⇒ L4 在另一侧）。先这样做再对像素，比反过来省一轮。
- ⊗ 用 `circle(radius:.19)` + 两条 ±.13 对角线；⊙ 用同半径圆 + `radius:.06` 实心点。
  两者共用半径才能让人一眼看出是同一套符号。
- 旋转环：`circle((0,3.77), radius:(.78,.2))` 整椭圆 + 在 θ=-20° 处放实心三角，
  方向 (.35,.94)（即沿椭圆"从前侧绕到右端继续向上"的切向）。第一版椭圆 .85/.26、
  三角 .17，视觉上比原图粗一档，缩到 .78/.20/.13 后匹配。

## fig69-addpair（矢量加法两栏 a/b）

要素：两栏各自的 x/y 轴、A（近水平）、B（左上）、b 栏的 C=A+B、从 A 末端出发的
虚线平移 B（末端箭头与 C 箭头同点重合）、A+B / C / A / B / x / y 标签、(a)(b) 栏号。

- 两栏共用一个 `panel(ox, show-sum)` 闭包，`add(O, p)` 平移，布尔参数控制增量画法，
  和 batch21 的 fig65 同一套路；栏间距 8.3 单位刚好不碰。
- 虚线平移矢量的终点必须与 C 的终点严格相等（都取 `add(O, C)`），两个箭头叠在同一点
  正是原图的样子；若各自估像素会出现两个错开的箭头头。

## 本批踩到的坑（重要）

Typst 的 `$vec(A)$` **不是**箭头符号，而是向量括号函数，渲染成 `(A)`。图上所有带箭头的
矢量标签必须写 `$arrow(A)$`。用一次 `probe.typ` 把 `arrow(A)` / `accent(A, arrow)` /
`attach(A, t: arrow.r)` / `A.arrow` 四个候选一起编译验证，四个都能过，但只有 `arrow(A)`
的形态与原图一致。`vec(A, delim: none)` 直接编译失败。

另外：`[(a)]` 这类纯文本标签不要写成 `[$(a)$]`——数学模式会把 a 变成斜体，和原图的
罗马体栏号不一致。
