## 本批新增的做法

1. **纯直线图用「白色面域 + 8 向极值」反求顶点**（`corners.py`）。
   把每个被描边围住的白面当一个区域，对每个区域取 x±、y±、x+y±、x−y± 八个方向的极值点，
   三角形的三个顶点必然落在这八个候选里。dt18 的三个面板 22 条线段一次成型。
   注意：极值点是「面域」的角，比真正的描边中心线内缩约半个笔宽（此处 3–8 px），
   交点/垂足位置要再用逐行 run 复核。
2. **腐蚀找实心点**。`binary_erosion(ink, ones(k,k))` 后剩下的连通块就是圆点与粗节点，
   中心即点坐标，比肉眼从缩略图估坐标准得多（dt18 的 c1、c2 两点由 k=5 直接给出）。
3. **开放曲线无法用区域追踪时，逐行/逐列取 run 中心采样**。
   近竖直的弧按行采样，近水平的弧按列采样，两条互补即可覆盖整条曲线；
   端点处 run 会与相邻曲线合并（宽度突增），要剔除。dt24 四条弧全部这样得到。
4. **虚线箭头的 dash 周期要量**。dt24 源图 dash 35 px / gap 12 px，
   换算 `dash: (6.7pt, 2.3pt)`（1 源 px ≈ 0.1916 pt），比直接用 `"dashed"` 贴合得多——
   逐带 psk 显示每段 dash 的 mean 都是 0.00–0.02。
5. **端点内缩规则**：源图墨迹 bbox 的极值 = 中心线端点 ± 半笔宽。
   dt24 第一次把弧的端点画在墨迹极值（y=19）上，结果整图比源图高 9 px、ar 差 2.2%；
   把端点收到中心线（y=22 / y=419）后 ar 差降到 1.3%。

## 踩的坑

- 手工「目测」顶点会系统性偏小。dt18 第一版三角形 (c) 用了面域 bbox 的 733/970，
  实际墨迹到 724/982，整图小了 1.5%，scale 掉到 2.6364；改成实测极值后回到 2.6005。
- 顶点在描边交点处，`trace3` 的外轮廓会给出缺口（notch）而非尖角：
  dt18 顶部 (493,17)(501,27)(511,17) 是两条边被内部辐条切开的痕迹，
  真实顶点要把两条边延长求交（≈(502,13)）。
- `line(path: true, close: true, ..ring)` 里 `ring` 是坐标元组数组时可直接展开，
  不必逐条写 `line(a,b)`。
