## ft25-delta-peak

上下两栏：(a) δ 谱线，(b) 同一位置展宽成带右肩的峰。`S = 100 px/单位`，`13pt`，`0.9pt` 线宽。

- 分栏图把下栏基线设为 `y = 0`、上栏基线设成常量 `ya`，两栏共用一套 x 坐标。
- 峰形用解析式相加采样：`2.30/(1+(u/0.36)^2) + 0.16*exp(-((u-0.95)/0.50)^2)`。
- 书里 (a) 栏的高线被页面裁掉，重绘时让顶线伸到画布上沿即可。

## ft13-sampling

五格采样定理示意：Φ(v) → Φ_s(v) → Φ_p(v)，左侧 Φ_s(v) ↔ F(t)，右侧 Φ_p(v) ↔ 梳状采样。
`S = 148 px/单位`，`10pt`，`1.0pt` 线宽。

- 三个 helper 把整张图压成几十行：`wave` 是"正峰 + 负肩"的小波，周期波列用
  `for k { s = s + wave(x, x0 + k*T) }` 叠加；`envelope` 同时供 F(t) 的光滑曲线和梳状图上的
  虚线包络使用，改一处两栏同步；`curve(x0, x1, step, f)` 统一采样成 `line(path: true, ..pts)`。
- 先用 numpy Hough 定三条水平基线（y=80/248/555）和两条竖直标记线（x=215/845），五格一次到位。
- 双向竖箭头是两根并排短线、箭头方向相反，不要在同一根线上同时挂 `start`/`end` 标记。

## ft14-lens-fringe

条透镜成像 + 屏上条纹：虚光轴、孔径面、平凸透镜、四条光线、θ/α 角弧、`w` 双箭头、`I(α)` 条纹曲线。
`S = 148 px/单位`，`12pt`，`0.8pt` 线宽。原点取主光线与光轴的交点 (615,428)。

- 光线全部用"覆盖度检验"确认：沿候选线段每 2 px 取样，检查 ±2 px 内是否有墨，
  覆盖率 >0.75 才认作真线。这样把 Hough 合并出来的假线（如 y≈300 的"水平线"）筛掉，
  并确认主光线是一整条直线 (13,543)→(1310,295)，另两条从透镜上下沿会聚到屏上同一点 (1300,353)。
- 透镜弯面用参数式而非圆弧：`x = 0.37 - 0.24*sin(180deg*s)`，`y = 1.20 - 2.36*s`，
  三个实测点（上下端点 + 顶点）直接决定系数。
- 条纹曲线是"横坐标 = 位置、纵坐标 = 强度"的竖画正弦：`x = 4.18 + 0.28*sin((2.28-y)/0.52*360deg)`，
  y 从 2.28 采样到 -1.82。第一版振幅 0.135、步长 0.024 导致曲线只画到一半高度，是量行数据时
  只截了 `x>1150` 窗口造成的低估。
- 角弧 helper 传参：CeTZ 里 `calc.deg` 不存在，角度一律 `(数值) * 1deg` 生成，别写 `calc.deg`。
