## fig64 一次通过要点

- 分量尺寸线：竖直细线 + 两端短横帽，`A_y ĵ` 用"垂直双箭头短段 + 波浪引线"。
  波浪引线 = 一条 bezier，两个控制点分居弦两侧（`ctrl1` 在弦右、`ctrl2` 在弦左）。
- 花括号用两条 bezier 在中间点相交成尖：
  `bezier((3.15,.78), (3.5,2.66), (3.48,1.05), (3.48,2.35))` +
  `bezier((3.5,2.66), (3.15,4.55), (3.48,2.95), (3.48,4.3))`，
  尖点 x 略大于两端 x，读起来就是书里的右向大括号。
- 标签文字长度决定几何尺度：`C_y ĵ = A_y ĵ + B_y ĵ` 约 5.6 单位宽，
  正好与原书"文字块 ≈ 三角形宽"的比例吻合，所以三角形取 5 单位宽即可，不必再调。

## fig65 失败—修正记录

首版结构、箭头方向全对，但四边环相对轴架偏小偏细，读起来像"坐标轴上的小记号"
而不是原书那种粗线方环。把方环半边长 1.0→1.25、环线宽 1.8→2.3pt、
轴架 1.1→1.4pt 后通过。

关键语法：`mark: (end: "<")` 是在**终点**放一个 "<" 形标记（指向起点方向），
所以要让箭头反向不必交换 line 的两个端点，直接换标记字符即可——
闭合环的四条边可以固定按同一顺序书写，只改标记，代码里用
`if cw { "<" } else { ">" }` 一个布尔就生成 (a)/(b) 两版。
