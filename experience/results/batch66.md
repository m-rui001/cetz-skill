## 这一批学到的

### 1. 虚线必须逐段画，不能用 `dash:` 图案

指标是单向的（渲染墨点 → 最近源墨点）。源图的虚线之间有 8–10 px 的空隙，
我若用 CeTZ 的 `stroke: (dash: "6 4")`，相位对不上就会把渲染墨放进源图空隙里，
那部分点的最近距离直接是半段空隙长度，均值立刻炸。

做法：虚线段在连通分量里本来就是各自独立的块，直接逐块取端点连线。

```python
lab, n = ndimage.label(g, structure=np.ones((3,3)))
for i in range(2, n+1):
    ys, xs = np.nonzero(lab == i)
    if ys.min() > 200: continue          # 底部的文字
    if xs.min() < 50:  continue          # 左侧 t_i 标签
    x0, x1 = xs.min(), xs.max()
    ya = ys[xs <= x0+2].mean(); yb = ys[xs >= x1-2].mean()   # 两端中心，自带倾斜
    dash.append((x0, ya, x1, yb))
```

dt39 得到 21 段，每段一条 `line`，编译一次就 0.37 px。
端点用"最左/最右 3 列的墨迹中心"而不是整段均值，虚线的整体倾斜就自动带上了。

### 2. 相切的"曲线 + 直线"：按列取 run，把切点钉在实心点上

dt6 的抛物线与 Z 线只有一个像素级接触区（x 297–380 合成一个 run）。
提取时先按两端量出直线 `ly(x)`，再按列取"中心离 `ly(x)` 超过 6 px"的唯一 run：

```python
cand = [t for t in runs(g[:, x]) if abs((t[0]+t[1])/2 - ly(x)) > 6]
if len(cand) == 1 and cand[0][1] - cand[0][0] <= 14: ...   # 长度上限挡掉穿到文字/边界的列
```

合并区（83 列）线性插值补上——那里曲线本来就是平的，插值误差可忽略。
最后把插值出来的切点强制替换成实心点圆心 `(340, 254.5)`，曲线和点在几何上严格共点，
叠加图上不会出现"点偏在线旁边"的毛刺。

顺手又验证了一次：**二次曲线拟合仍然没用**。同一批点做 `polyfit(deg=2)`，
顶点位置对（335, 254），但 max 残差 9.6 px、rms 2.7 px——这条手绘感抛物线不是真抛物线。
直接用实测折线（每 4 列取一点，156 点）才是正解。

### 3. 实心点的半径从"线外面露出的那一半"量

点压在主线上，整块墨看不出圆。取主线**下边界以外**的墨迹：
dt39 左点 y 314–331 都在轴（322–325）之外鼓出来 → 中心 (376, 322)、半径 9。
dt6 同理，用 y 258–262（线下方）的逐行宽度反推：底在 262、最宽在 258 → 圆心 y≈254、r≈8。
比"看着画个点"准得多，也不用试。

### 4. CeTZ 0.4.2 的 `circle` 签名

`circle(px(x,y), radius: r/S, fill: black, stroke: none)`。
- 位置参数写半径 → `Failed to resolve coordinate system: 0.054`（半径被当成第二个点）。
- `center:` 具名 → `circle expects one or two points, got ()`。
半径同样是 CeTZ 单位，必须 `/ S`。

### 5. 字号规则再验三次

`font_pt ≈ cap_px × 0.2736`：
- dt38 的 `f(R^1)` 源宽 79 px → 6.5 pt。我先按 8 pt 画，渲染宽 99 px（+25 %），
  均值 0.84；改成 6.5 pt 后 **0.84 → 0.31**，`ar` 差从 1.5 % 收到 0.6 %。
- dt38 / dt6 的 `Z` 源 21–22 px 宽、cap 24 px → 都是 6.5 pt。
- dt39 的 `t_i` / `i` / `i+1` 用 7 pt 一遍过（`meas.py` 复核宽度差 < 4 %）。

文字撑墨框这条（batch65 记的）在这里 again 生效：dt38 的墨框左右极值都由标签决定，
字号错 23 % 就是整张图被百分比级拉伸。
